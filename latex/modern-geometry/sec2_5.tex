\section*{2.5 쌍대 구면 삼각형}

쌍대(혹은 ``극'') 삼각형에서 꼭짓점은 원래 삼각형의 변에, 변은 원래 삼각형의 꼭짓점에 대응된다.
이 ``쌍대성''을 사용하면 한쪽의 정리가 다른 쪽 정리를 자동으로 제공하여 수고를 반으로 줄일 수 있다.

\begin{tcolorbox}[
  colback=teal!4, colframe=teal!65!black,
  title=정의 2.5.1 (쌍대 구면 삼각형),
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

$\triangle ABC$를 구면 삼각형이라 하자.
\textbf{쌍대 삼각형} ${}^*\!\triangle ABC$는
$\vec{A}^*,\,\vec{B}^*,\,\vec{C}^*$가 다음과 같은 구면 삼각형 $\triangle A^*B^*C^*$이다.
\[
  \vec{A}^* = \frac{\vec{B}\times\vec{C}}{R\sin\angle a},\qquad
  \vec{B}^* = \frac{\vec{C}\times\vec{A}}{R\sin\angle b},\qquad
  \vec{C}^* = \frac{\vec{A}\times\vec{B}}{R\sin\angle c}
\]
여기서 $R$은 구의 반지름이고,
$\vec{A}^* = \overrightarrow{OA^*}$, $\vec{B}^* = \overrightarrow{OB^*}$,
$\vec{C}^* = \overrightarrow{OC^*}$이다.

\end{tcolorbox}

분모 $R\sin\angle a$ 등은 $|\vec{A}^*|=|\vec{B}^*|=|\vec{C}^*|=R$이 되도록 크기를 조절한다.
$\vec{A}^*$는 변 $a$를 포함하는 평면 $\overline{BCO}$에 수직이며(마찬가지로 $\vec{B}^*$, $\vec{C}^*$도 각각 $b$, $c$를 포함하는 평면에 수직),
이런 의미에서 쌍대 삼각형의 꼭짓점은 원래 삼각형의 변에 대응된다.
아래 정리 2.5.1은 역으로 쌍대 삼각형의 변이 원래 삼각형의 꼭짓점에 대응됨을 보여주고,
따름정리 2.5.3은 대응하는 각과 변이 서로 보각$^{10)}$ 관계임을 밝힌다.

\begin{tcolorbox}[
  colback=red!4, colframe=red!60!black,
  title=정리 2.5.1,
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

쌍대 삼각형의 꼭짓점 $A^*$, $B^*$, $C^*$에 대해 $a^*$, $b^*$, $c^*$를 각각의 대변이라 하면 다음이 성립한다.
\[
  \vec{A} = s\!\left(\frac{\vec{B}^*\times\vec{C}^*}{R\sin\angle a^*}\right),\qquad
  \vec{B} = s\!\left(\frac{\vec{C}^*\times\vec{A}^*}{R\sin\angle b^*}\right),\qquad
  \vec{C} = s\!\left(\frac{\vec{A}^*\times\vec{B}^*}{R\sin\angle c^*}\right)
\]
단, $s = \pm 1$은 $\det[\vec{A},\vec{B},\vec{C}]$의 부호이다.$^{11)}$

\end{tcolorbox}

\textbf{증명.}\quad
정의에 의해
\begin{equation}
  \vec{B}^*\times\vec{C}^*
  = \frac{(\vec{C}\times\vec{A})\times(\vec{A}\times\vec{B})}{R^2\sin\angle b\sin\angle c}
  \tag{2.15}
\end{equation}
벡터 항등식 $\vec{X}\times(\vec{Y}\times\vec{Z}) = (\vec{X}\cdot\vec{Z})\vec{Y} - (\vec{X}\cdot\vec{Y})\vec{Z}$로부터
\[
  (\vec{C}\times\vec{A})\times(\vec{A}\times\vec{B})
  = \bigl((\vec{C}\times\vec{A})\cdot\vec{B}\bigr)\vec{A}
   - \bigl((\vec{C}\times\vec{A})\cdot\vec{A}\bigr)\vec{B}
  = \det[\vec{A},\vec{B},\vec{C}]\,\vec{A}
\]
이를 (2.15)에 대입하면
$\vec{B}^*\times\vec{C}^* = \dfrac{\det[\vec{A},\vec{B},\vec{C}]}{R^2\sin\angle b\sin\angle c}\,\vec{A}$.
따라서 $\vec{A}$는 $\vec{B}^*\times\vec{C}^*$와 같은 방향이고,
$|\vec{B}^*|=|\vec{C}^*|=R$이므로
$\left|\dfrac{\vec{B}^*\times\vec{C}^*}{R\sin\angle a^*}\right| = R = |\vec{A}|$이다.
따라서 $\vec{A} = s\!\left(\dfrac{\vec{B}^*\times\vec{C}^*}{R\sin\angle a^*}\right)$이 성립하고,
나머지 등식도 같은 방법으로 얻는다. \hfill $\square$

\smallskip
\noindent$^{10)}$\,\small 두 보각은 합하면 $180°$가 된다.\normalsize\\
\noindent$^{11)}$\,\small $\det[\vec{A},\vec{B},\vec{C}]$는 $\vec{A},\vec{B},\vec{C}$를 행벡터로 갖는 $3\times 3$ 행렬의 결정자이다.\normalsize

\begin{tcolorbox}[
  colback=red!4, colframe=red!60!black,
  title=따름정리 2.5.1 (쌍대 삼각형의 쌍대),
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

\[
  {}^*({}^*\!\triangle ABC) =
  \begin{cases}
    \triangle ABC, & \det[\vec{A},\vec{B},\vec{C}] \ge 0 \\[4pt]
    \triangle(-A)(-B)(-C), & \det[\vec{A},\vec{B},\vec{C}] \le 0
  \end{cases}
\]

\end{tcolorbox}

\begin{tcolorbox}[
  colback=red!4, colframe=red!60!black,
  title=따름정리 2.5.2,
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

${}^*({}^*\!\triangle ABC) \cong \triangle ABC$

\end{tcolorbox}

\textbf{증명.}\quad
따름정리 2.5.1에 의해 ${}^*({}^*\!\triangle ABC)$는 $\triangle ABC$와 같거나
구의 중심에 대한 반사이다. \hfill $\square$

\begin{tcolorbox}[
  colback=red!4, colframe=red!60!black,
  title=따름정리 2.5.3,
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

쌍대 삼각형의 꼭짓점 $A^*$, $B^*$, $C^*$에 대해 $a^*$, $b^*$, $c^*$를 각각의 대변이라 하면 다음이 성립한다.
\begin{align}
  \angle A + \angle a^* = \angle A^* + \angle a &= 180°, \notag\\
  \angle B + \angle b^* = \angle B^* + \angle b &= 180°, \tag{2.16}\\
  \angle C + \angle c^* = \angle C^* + \angle c &= 180° \notag
\end{align}

\end{tcolorbox}

\textbf{증명.}\quad
정의 2.5.1과 보조정리 2.3.1로부터
\[
  \angle a^*
  = \angle(\vec{B}^*,\vec{C}^*)
  = \angle(\vec{C}\times\vec{A},\;\vec{A}\times\vec{B})
  = \angle(-\vec{A}\times\vec{C},\;\vec{A}\times\vec{B})
  = 180° - \angle A
\]
이므로 $\angle A + \angle a^* = 180°$이다.
이 결과를 $\triangle A^*B^*C^*$에 적용하면
\begin{equation}
  \angle A^* + \angle a^{**} = 180° \tag{2.17}
\end{equation}
따름정리 2.5.2에 의해 $\angle a^{**} = \angle a$이므로 $\angle A^* + \angle a = 180°$이 성립한다.
나머지 두 식도 같은 방법으로 증명된다. \hfill $\square$

\subsection*{연습문제 2.5}

\textbf{문제 2.5.1}\quad
$\mathbb{R}^3$에서 중심이 원점인 단위 구에 있는 세 점이
$A = (0,0,1)$,\; $B = \bigl(\tfrac{\sqrt{2}}{2},0,\tfrac{\sqrt{2}}{2}\bigr)$,\; $C = \bigl(0,\tfrac{\sqrt{3}}{2},\tfrac{1}{2}\bigr)$일 때,

a) $\triangle ABC$의 쌍대 삼각형의 꼭짓점을 찾아라.

b) 직접 계산을 통해 정리 2.5.1, 따름정리 2.5.1, 따름정리 2.5.3이 성립함을 확인하여라.

c) 단위 구에 $\triangle ABC$와 ${}^*\!\triangle ABC$를 그려라.
