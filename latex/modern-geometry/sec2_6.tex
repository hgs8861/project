\section*{2.6 각에 대한 코사인 법칙}

다음 결과는 쌍대성을 사용하여 변에 대한 코사인 법칙으로부터 바로 얻을 수 있다.

\begin{tcolorbox}[
  colback=red!4, colframe=red!60!black,
  title=따름정리 2.6.1 (각에 대한 코사인 법칙),
  fonttitle=\bfseries, boxrule=0.5mm, arc=3mm]

\begin{equation}
  \cos\angle A = -\cos\angle B\cos\angle C + \sin\angle B\sin\angle C\cos\angle a
  \tag{2.18}
\end{equation}

\end{tcolorbox}

\textbf{증명.}\quad
쌍대 삼각형에 정리 2.4.1을 적용하면
\begin{equation}
  \cos\angle a^* = \cos\angle b^*\cos\angle c^* + \sin\angle b^*\sin\angle c^*\cos\angle A^*
  \tag{2.19}
\end{equation}
따름정리 2.5.3의 $\angle a^* = 180°-\angle A$, $\angle b^* = 180°-\angle B$, $\angle c^* = 180°-\angle C$를
$\cos(180°-\theta)=-\cos\theta$, $\sin(180°-\theta)=\sin\theta$와 함께 대입하면 식 (2.18)을 얻는다.
\hfill $\square$

\medskip
세 꼭짓각이 주어지면 구면 삼각형은 완전하게 결정된다.
따라서 두 구면 삼각형의 세 꼭짓각이 동일하면 합동이다 — 평면에서는 단지 닮음임과 대조된다.

\bigskip
\textbf{보기 2.6.1}\quad
$\angle A = 60°$, $\angle B = 70°$, $\angle C = 80°$인 구면 삼각형의 세 호각을 구하여라.

\medskip
\textbf{풀이.}\quad
각에 대한 코사인 법칙에 수치를 대입하면 다음과 같다.
\begin{align*}
  \cos\angle a
  &= \frac{\cos 60° + \cos 70°\cos 80°}{\sin 70°\sin 80°}
   = \frac{.50000 + (.34202)(.17365)}{(.93969)(.98481)}
   \approx .60447 \\[4pt]
  \cos\angle b
  &= \frac{\cos 70° + \cos 60°\cos 80°}{\sin 60°\sin 80°}
   = \frac{.34202 + (.50000)(.17365)}{(.86603)(.98481)}
   \approx .50283 \\[4pt]
  \cos\angle c
  &= \frac{\cos 80° + \cos 60°\cos 70°}{\sin 60°\sin 70°}
   = \frac{.17365 + (.50000)(.34202)}{(.86603)(.93969)}
   \approx .42353
\end{align*}
따라서 $\angle a \approx 52.809°$, $\angle b \approx 59.813°$, $\angle c \approx 64.943°$이다. \hfill $\square$

\medskip
구면에서 한 꼭짓점에 모이는 여러 각은 접평면에서처럼 더해진다.
예를 들어 그림 2.13에서 $\angle a + \angle b + \angle c = 360°$이다.

\bigskip
\textbf{보기 2.6.2}\quad
각 변의 길이가 $10\,\text{cm}$인 정십이면체에서 꼭짓점에서 중심까지의 거리를 구하여라
(그림 2.14).

\medskip
\textbf{풀이.}\quad
$A$, $B$를 인접한 꼭짓점, $O$를 중심이라 하자.
$\angle AOB$를 구하면 평면 삼각형의 코사인 법칙으로부터
\begin{equation}
  (10\,\text{cm})^2 = 2(OA)^2(1 - \cos\angle AOB)
  \tag{2.20}
\end{equation}
이므로 $OA$를 얻을 수 있다.
정십이면체를 외접구에 사영하면 열두 개의 합동인 ``구면 오각형''이 생기고,
각 오각형을 중심 $C$와 꼭짓점을 이어 다섯 개의 이등변 구면 삼각형으로 나눈다(그림 2.14).
각 꼭짓점에서 세 오각형이 모이므로 오각형의 각 = $360°/3 = 120°$이고,
두 삼각형이 꼭짓점에서 만나므로 $\angle A = \angle B = 60°$, 다섯 삼각형이 $C$에서 만나므로 $\angle C = 72°$이다.
각에 대한 코사인 법칙을 적용하면
\[
  \cos\angle\widehat{AB}
  = \frac{\cos 72° + \cos^2 60°}{\sin^2 60°}
  \approx 0.74536
\]
식 (2.20)으로부터 $OA \approx 10/\sqrt{2-2(0.74536)} \approx 14.01\,\text{cm}$이다. \hfill $\square$

\subsection*{연습문제 2.6}

\textbf{문제 2.6.1 (ASA와 AAA)}\quad
주어진 정보로 $\triangle ABC$를 풀어라.
\begin{enumerate}[(a)]
  \item $\angle A = 65°$,\; $\angle B = 75°$,\; $\angle c = 85°$
  \item $\angle A = 65°$,\; $\angle B = 75°$,\; $\angle C = 85°$
\end{enumerate}

\textbf{문제 2.6.2 (그림 2.15 참조)}\quad
각 변의 길이가 $10\,\text{cm}$일 때 중심으로부터 꼭짓점까지의 거리를 구하여라.
\begin{enumerate}[(a)]
  \item 정사면체
  \item 깎은 정이십면체
    (열두 개의 합동인 정오각형과 스무 개의 합동인 정육각형으로 이루어진 축구공 모양의 다면체.
    각 꼭짓점에서 오각형 하나와 육각형 두 개가 만난다. 그림 2.15 참조.)
\end{enumerate}
